# Who's using YAMBLOG?

If you run a site or app built with any of the `@yamblog/*` packages, we would love to hear about it.

This list is the only way the project learns who is actually using it. The packages contain no telemetry and never phone home, and that will not change without an explicit opt-in. Download counts on npm mostly reflect CI runs, mirrors and bots, so a line from you here tells us far more about what to keep stable and what to build next.

## Add your site

Either:

- **Open a pull request** that adds a row to the table below (keep it alphabetical after the first row), or
- **Post in [GitHub Discussions](https://github.com/yamblog/yamblog/discussions)** with your site name, URL and the packages you use, and a maintainer will add it for you.

Only add sites you own or have permission to list. To remove an entry, open a PR or a discussion at any time.
